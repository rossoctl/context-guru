# Proposal: a task-driven cg band

**Status:** discovery. No implementation, no spec, no plan yet.

This folder proposes a redesign of the band that the `context-guru` Claude Code plugin
draws above the prompt. The band is a Claude Code mod:
[`context-guru-plugin/hooks/register.tsx`](../../../context-guru-plugin/hooks/register.tsx)
and [`model.ts`](../../../context-guru-plugin/hooks/model.ts) in this repo (plugin
version 0.7.2). All work here is analysis and mockups. Nothing in the plugin was changed.

The screenshots and the live numbers came from the **internal build** of the same mod
(version 0.6.1, command prefix `/cg:`, header "From the cg plugin"). The mockups copy that
look. [01-analysis.md](01-analysis.md), section 8, lists what version 0.7.2 does
differently.

This folder is under `docs/proposals/`, which `mkdocs.yml` leaves out of the site build.

## The idea in one paragraph

Today the band shows the cache clock as a number, with a `↻` mark and several words.
The number is a forecast that assumes every planned ping succeeds, and the band does
not separate a planned extension (free, potential) from an activated one (a paid ping).
The proposal draws the cache as a **bar to scale**: a dark part for time already
passed, a green block for the built-in TTL, and one block per extension. A **dashed**
block is planned. A **solid** block is activated and paid. One link, `more 5 mins
($0.01)`, adds an extension. The words, the state glyphs and the tip row go away.

## What is verified and what is not

**Verified** by reading the source of the internal build (0.6.1) and of this repo's
plugin (0.7.2), and in one live session of the internal build: the band structure, the
colors, the data flow, the `cachestate` fields, and the reason the clock can show more
than 5 minutes. The 0.7.2 band was read, not run.

**Not verified:**
- What a manual click adds to the plan, and whether it counts against X.
- The cost of one ping. The link shows `$0.01`, which is the warm message price.
- The split of the planned extensions. Their lengths are inferred from one read.
- Any rule or data for the context verdict (compact, sub-agent, new session).
- Whether the VS Code surface supports a hover card on the band.

Numbers in the mockups are examples taken from one session. They are not a spec.
