# PR #578 End-to-End Review Harness — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and run a sandboxed harness that installs PR #578 from scratch in a container, feeds it seeded mock Claude Code history and replayed live traffic, and checks every dashboard figure against an independent ground truth.

**Architecture:** One Docker image built from the checkout. A host script `e2e/run.sh` runs phases inside it in order: preflight → generate → install → import → replay → api → ui → skill → assert → report. Ground truth lives in a seeded manifest; `oracle.py` turns it into `expected.json` with logic that imports nothing from the PR. Two tiers share the harness and differ only in which manifest they load.

**Tech Stack:** Python 3.11 (stdlib only: `json`, `random`, `http.server`, `urllib`, `unittest`), Node 24 (built-in `WebSocket`, no npm packages), Debian bookworm `chromium`, Docker, the repo's Go 1.26 toolchain, Bash.

**Spec:** `docs/superpowers/specs/2026-10-20-pr578-e2e-review-design.md` — read it before Task 1. This plan argues from it.

## Global Constraints

- Branch: `e2e/pr578-review`, off `feat/insights-per-item-inventory`. Nothing in `e2e/` is shipped; nothing outside `e2e/` and `docs/superpowers/` is modified.
- Isolation: inside the container `HOME=/sandbox`. Only `results/` is mounted from the host. The host's `~/.claude`, `~/.local`, and port 8788 are never touched.
- Proxy inside the container: port 8788. Published to the host as 18788.
- Fake upstream inside the container: port 9000, Anthropic `/v1/messages`, both `stream: true` (SSE) and plain JSON.
- Timeline: day 0..42, install at day 28 12:00 UTC. Days 0–27 are transcripts only; days 28–42 are transcripts AND replayed.
- Seed: `20261020`. Two generations with the same seed must be byte-identical.
- The oracle (`e2e/oracle.py`) imports no PR code and reads no PR output. It reads only the manifest.
- Money: property checks only (unused `usd > 0`; used items carry no waste; project total == sum of rows; pooled total ≥ each project). No exact dollar values.
- Verdicts: exactly `PASS`, `FAIL`, `BLOCKED`, `KNOWN`.
- Smoke tier: under 5 minutes; any check failure stops the run before tier 2.
- Python: stdlib only, no `pip install`. Node: no npm packages.
- Commits: `git commit -s`, conventional prefix, trailer `Assisted-By: Claude (Anthropic AI) <noreply@anthropic.com>`. Never `Co-Authored-By`.
- No real model calls, no API keys, no cost. The proxy's `--anthropic-upstream` is always `http://127.0.0.1:9000`.

## Review Focus

Inputs the spec implies but no happy-path test exercises, most likely to bite first:

1. **A replayed request the proxy cannot attribute to a project** (no `Primary working directory:` marker, or a relative path) — must land as unattributed, never as a fake project in the picker. Pinned in Task 5 (`test_replay_body_without_marker_is_marked_unattributed`) and asserted in Task 9 (`picker_has_no_unattributed_entry`).
2. **SSE replies that end without a `message_stop`** (client-side cut-off) — the proxy must still record the row. Pinned in Task 4 (`test_upstream_can_truncate_a_stream`) and replay sends 2 truncated streams in the full tier.
3. **The proxy restarting mid-replay** — rows written before the restart must survive and the dashboard must reopen the same DB. Pinned in Task 7 (`restart_between_replay_halves`) as a full-tier phase step.
4. **A transcript line that is not valid JSON or is truncated** (normal for a live session) — the importer must skip it and import the rest. Pinned in Task 3 (`test_generator_emits_one_truncated_final_line`) and asserted in Task 9 (`import_count_equals_valid_turns`).
5. **A dark-mode or 400px render that hides a number** (text clipped, overflowing, or same colour as the background) — the DOM value is present but unreadable. Pinned in Task 8: `snap.mjs` records `scrollWidth > clientWidth` overflow and the computed contrast of every headline figure; Task 9 fails any figure under 3:1 or overflowing.

| `e2e/report.py` | `results/` → `summary.md` + `report.html` |
| `e2e/phases.sh` | In-container phase runner; one function per phase; writes `results/logs/<phase>.log` |
| `e2e/mutate.sh` | Mutation round: apply each of 5 breaks to PR code, rebuild, re-run assert, restore |
| `e2e/Dockerfile.e2e` | Build stage (repo Go build) + runtime (python3, nodejs, chromium, curl, git, make, go) |
| `e2e/run.sh` | Host entry: build image, run a tier, copy results, re-run failures on `main` |
| `e2e/tests/` | `unittest` tests for the Python units; `node --test` for nothing (snap.mjs is exercised in Task 8's own check) |

Every Python unit is runnable on the host too (`python3 -m unittest discover e2e/tests`), so the harness is tested before it is trusted inside the container.

```python
        self.assertGreaterEqual(len(m.sessions), 38)
        self.assertLessEqual(len(m.sessions), 44)

        self.assertGreaterEqual(turns, 8000, "~9k assistant turns, like the real 9,006")
        self.assertLessEqual(turns, 10000)

        ratio = sum(len(s.turns) for s in stress.sessions) / sum(len(s.turns) for s in full.sessions)
        self.assertGreaterEqual(ratio, 9.0)

        cells = mf.coverage(m)

    def test_mixed_session_spans_the_install(self):

        s = [x for x in m.sessions if x.project == "mixed"][0]
```

```python
"""The ground truth for the PR #578 end-to-end review.

Every other file in e2e/ derives from this: the transcripts, the installed inventory, the replayed
traffic, and the expected values. Nothing here imports PR code. Seeded, so a run is reproducible.
"""
from __future__ import annotations

import json
import random
from dataclasses import asdict, dataclass

SEED = 20261020
T0 = 1788393600000  # 2026-09-07 00:00 UTC
DAYS = 43
INSTALL_DAY = 28
DAY = 86_400_000


def day_ms(day: int, hour: int = 0) -> int:
    return T0 + day * DAY + hour * 3_600_000


@dataclass(frozen=True)
class Capability:
    name: str
    kind: str
    owner: str
    on_disk: bool
    declared: bool
    tokens: int
    self_owned: bool


@dataclass(frozen=True)
class Project:
    key: str
    root: str
    folders: tuple
    exists: bool
    measured: bool
    transcript_dir: str


@dataclass(frozen=True)
class Invocation:
    cap: str


@dataclass(frozen=True)
class Turn:
    ts: int
    cwd: str
    fresh: int
    cache_read: int
    cache_write: int
    output: int
    invocations: tuple
    stream: bool
    truncate: bool


@dataclass(frozen=True)
class Session:
    id: str
    project: str
    turns: tuple


@dataclass(frozen=True)
class Manifest:
    tier: str
    seed: int
    install_ms: int
    projects: tuple
    capabilities: tuple
    sessions: tuple
    home: str


def measured(t: Turn, m: Manifest) -> bool:
    return t.ts >= m.install_ms


# --- capabilities -----------------------------------------------------------------------------

def _caps(full: bool) -> list:
    c = []

    def add(name, kind, owner, on_disk=True, declared=True, tokens=300, self_owned=False):
        c.append(Capability(name, kind, owner, on_disk, declared, tokens, self_owned))

    # MCP servers, three tools each. States: never / one-project / stale / post-install-only.
    for server in (("docs-search", "notes-db", "ticketer", "metrics") if full else ("docs-search",)):
        for tool in ("search", "fetch", "list"):
            add(f"mcp__{server}__{tool}", "mcp_tool", server, tokens=420)
    # Plugin skills: every state.
    plug = {
        "toolkit": ("planner", "reviewer", "debugger", "tester", "writer", "never-a", "never-b"),
        "helpers": ("formatter", "linter", "old-trick", "late-adds"),
    } if full else {"toolkit": ("planner", "never-a")}
    for p, names in plug.items():
        for n in names:
            add(f"{p}:{n}", "plugin_skill", p, tokens=180)
    # Marketplace skills (bare names): never / one-project / pre-install-only.
    for n in (("pdf", "xlsx", "slides", "canvas", "brand", "memo") if full else ("pdf",)):
        add(n, "marketplace_skill", "acme-agent-skills", tokens=160)
    # Bundled: invoked, on disk nowhere, declared in the prompt.
    add("chartmaker", "bundled_skill", "(bundled)", on_disk=False, tokens=140)
    # Built-in tools: used in several projects, never removable.
    for n in (("Bash", "Read", "Edit", "Write", "Grep") if full else ("Bash",)):
        add(n, "builtin", "(builtin)", on_disk=False, tokens=900)
    # This tool's own skills, under both names it has shipped as.
    if full:
        for n in ("insights", "status", "dashboard"):
            add(f"context-guru:{n}", "plugin_skill", "context-guru", tokens=200, self_owned=True)
        add("cg:insights", "plugin_skill", "cg", tokens=200, self_owned=True)
    return c


# The (kind, state) cells the spec's matrix requires. `coverage` must contain all of them.
REQUIRED_CELLS = {
    "mcp_tool": ("never", "one", "stale", "post_only"),
    "plugin_skill": ("never", "one", "several", "stale", "pre_only", "post_only"),
    "marketplace_skill": ("never", "one", "pre_only"),
    "bundled_skill": ("one",),
    "builtin": ("several",),
    "self_owned": ("never", "one", "pre_only"),
}

# Which capability plays which state. Fixed, not random: the matrix must be filled every time.
_FULL_ROLES = {
    # cap name -> (state, projects that invoke it, window) ; window in {"pre","post","both"}
    "mcp__docs-search__search": ("one", ("alpha",), "both"),
    "mcp__notes-db__fetch": ("stale", ("beta",), "pre_early"),
    "mcp__ticketer__list": ("post_only", ("alpha",), "post"),
    "toolkit:planner": ("several", ("alpha", "beta", "gamma"), "both"),
    "toolkit:reviewer": ("one", ("beta",), "both"),
    "toolkit:debugger": ("stale", ("alpha",), "pre_early"),
    "toolkit:tester": ("pre_only", ("history-only", "deleted-proj"), "pre"),
    "toolkit:writer": ("one", ("my-repo",), "both"),
    "helpers:formatter": ("one", ("gamma",), "both"),
    "helpers:late-adds": ("post_only", ("beta",), "post"),
    "pdf": ("one", ("wanderer",), "both"),
    "xlsx": ("pre_only", ("history-only",), "pre"),
    "chartmaker": ("one", ("alpha",), "both"),
    "Bash": ("several", ("alpha", "beta", "gamma", "my-repo", "mixed", "wanderer", "home"), "both"),
    "Read": ("several", ("alpha", "beta", "gamma"), "both"),
    "Edit": ("several", ("alpha", "gamma"), "both"),
    "context-guru:insights": ("one", ("alpha",), "both"),
    "cg:insights": ("pre_only", ("beta",), "pre"),
}
_SMOKE_ROLES = {
    "mcp__docs-search__search": ("one", ("alpha",), "both"),
    "toolkit:planner": ("one", ("alpha",), "both"),
    "pdf": ("pre_only", ("history-only",), "pre"),
    "chartmaker": ("one", ("alpha",), "both"),
    "Bash": ("several", ("alpha", "gamma"), "both"),
}


def roles(m: Manifest) -> dict:
    return _SMOKE_ROLES if m.tier == "smoke" else _FULL_ROLES


def coverage(m: Manifest) -> set:
    """The (kind, state) cells this manifest fills, derived from roles plus never-invoked caps."""
    r = roles(m)
    cells = set()
    for cap in m.capabilities:
        kind = "self_owned" if cap.self_owned else cap.kind
        cells.add((kind, r[cap.name][0] if cap.name in r else "never"))
    return cells


# --- projects ---------------------------------------------------------------------------------

def _projects(full: bool, home: str, scale: int) -> list:
    def P(key, root, subs=(), exists=True, measured=True, extra=()):
        tdir = root.replace("/", "-")
        return Project(key, root, (root,) + tuple(f"{root}/{s}" for s in subs) + tuple(extra),
                       exists, measured, tdir)

    if not full:
        return [
            P("alpha", f"{home}/work/alpha"),
            P("gamma", f"{home}/work/gamma", subs=("server",)),
            P("history-only", f"{home}/work/history-only", measured=False),
        ]
    ps = [
        P("alpha", f"{home}/work/alpha"),
        P("beta", f"{home}/work/beta"),
        P("gamma", f"{home}/work/gamma", subs=("server", "docs/adr", "ops/compose", "ops/backup")),
        P("my-repo", f"{home}/work/my-repo"),
        P("deleted-proj", f"{home}/work/deleted-proj", exists=False, measured=False),
        P("history-only", f"{home}/work/history-only", measured=False),
        P("mixed", f"{home}/work/mixed"),
        P("wanderer", f"{home}/work/wanderer", extra=("/tmp/scratch-w",)),
        P("scratch-1", "/tmp/scratch-1", measured=False),
        P("scratch-2", "/tmp/scratch-2", measured=False),
        P("scratch-3", "/tmp/scratch-3"),
        P("home", home),
    ]
    if scale > 1:  # stress: ten copies of each non-home project, distinct roots
        ps = [p for p in ps if p.key == "home"] + [
            Project(f"{p.key}-{i}", f"{p.root}-{i}", tuple(f"{f}-{i}" if f.startswith(p.root) else f
                                                           for f in p.folders),
                    p.exists, p.measured, f"{p.transcript_dir}-{i}")
            for i in range(scale) for p in ps if p.key != "home"]
    return ps


# --- sessions ---------------------------------------------------------------------------------

def _usage(rng: random.Random):
    return (rng.randint(1, 40), rng.randint(20_000, 90_000), rng.choice((0, 0, 0, 4_000, 30_000)),
            rng.randint(100, 2_000))


def build(tier: str, seed: int = SEED, home: str = "/sandbox") -> Manifest:
    if tier not in ("smoke", "full", "stress"):
        raise ValueError(f"unknown tier {tier!r}")
    full = tier != "smoke"
    scale = 10 if tier == "stress" else 1
    rng = random.Random(seed)
    caps = tuple(_caps(full))
    projects = tuple(_projects(full, home, scale))
    install = day_ms(INSTALL_DAY, 12)
    rmap = _SMOKE_ROLES if not full else _FULL_ROLES
    sessions = []
    sess_per_project = 1 if not full else 3
    turns_per_session = 4 if not full else 220
    n_stream, n_trunc = 0, 0
    for p in projects:
        base = p.key.rsplit("-", 1)[0] if scale > 1 and p.key != "home" else p.key
        for si in range(sess_per_project + (1 if base in ("alpha", "beta") else 0)):
            sid = f"{p.key}-s{si:02d}-{rng.randrange(16**8):08x}"
            if base == "history-only" or base == "deleted-proj" or not p.measured:
                start = rng.randint(0, INSTALL_DAY - 4)
            elif base == "mixed" and si == 0:
                start = INSTALL_DAY - 1  # straddles day 28 12:00
            else:
                start = rng.randint(0, DAYS - 3)
            turns = []
            for ti in range(turns_per_session):
                day = min(DAYS - 1, start + (ti * 3) // turns_per_session)
                ts = day_ms(day, 8) + ti * 60_000 + rng.randint(0, 59_000)
                if base == "mixed" and si == 0:
                    ts = install - (turns_per_session // 2 - ti) * 600_000
                if not p.measured and ts >= install:
                    ts = install - 3_600_000 - ti * 60_000
                cwd = p.folders[ti % len(p.folders)] if len(p.folders) > 1 else p.root
                invs = []
                for cname, (state, users, window) in rmap.items():
                    if base not in users:
                        continue
                    pre = ts < install
                    ok = (window == "both" or (window == "pre" and pre) or
                          (window == "post" and not pre) or
                          (window == "pre_early" and ts < day_ms(6)))
                    if ok and ti % 7 == rng.randint(0, 6):
                        invs.append(Invocation(cname))
                fr, cr, cw, out = _usage(rng)
                is_post = ts >= install
                stream = is_post and rng.random() < 0.8
                n_stream += stream
                trunc = False
                if full and stream and n_trunc < 2 and base == "alpha" and ti > 10:
                    trunc, n_trunc = True, n_trunc + 1
                turns.append(Turn(ts, cwd, fr, cr, cw, out, tuple(invs), stream, trunc))
            sessions.append(Session(sid, p.key, tuple(turns)))
    return Manifest(tier, seed, install, projects, caps, tuple(sessions), home)


def to_json(m: Manifest) -> str:
    return json.dumps(asdict(m), sort_keys=True, indent=1)
```

```python
"""Expected values for the PR #578 review, from the manifest alone.

INDEPENDENT BY CONSTRUCTION: this imports nothing from the PR and reads none of its output. It
re-states the rules the PR is meant to follow, so a disagreement between this and the dashboard is
a finding rather than the code agreeing with itself. A test pins the import list.
"""
from __future__ import annotations

import argparse
import json
import sys

from e2e.gen import manifest as mf

SKILL_KINDS = ("plugin_skill", "marketplace_skill")


def _root_of(m: mf.Manifest) -> dict:
    """Every session id -> its project's root. Claude Code's grouping: a session belongs to the
    project it was filed under, whichever folder each turn ran in."""
    roots = {p.key: p.root for p in m.projects}
    return {s.id: roots[s.project] for s in m.sessions}


def expected(m: mf.Manifest) -> dict:
    caps = {c.name: c for c in m.capabilities}
    root_of = _root_of(m)
    invoked_anywhere = {i.cap for s in m.sessions for t in s.turns for i in t.invocations}

    # --- History -------------------------------------------------------------------------------
    installed = sorted(c.name for c in m.capabilities
                       if c.on_disk and not c.self_owned and c.kind in SKILL_KINDS)
    never = sorted(n for n in installed if n not in invoked_anywhere)
    owners: dict = {}
    for n in never:
        owners[caps[n].owner] = owners.get(caps[n].owner, 0) + 1
    self_names = {c.name for c in m.capabilities if c.self_owned}
    self_names |= {n for n in invoked_anywhere if n.startswith(("context-guru:", "cg:"))}

    # --- Cleanup -------------------------------------------------------------------------------
    measured_roots = sorted({root_of[s.id] for s in m.sessions for t in s.turns if mf.measured(t, m)})
    all_roots = sorted({p.root for p in m.projects})
    declared = [c for c in m.capabilities
                if c.declared and not c.self_owned and c.kind != "builtin"]
    unused, used = {}, {}
    for r in measured_roots:
        inv = {i.cap for s in m.sessions if root_of[s.id] == r
               for t in s.turns if mf.measured(t, m) for i in t.invocations}
        used[r] = sorted(inv)
        unused[r] = sorted(c.name for c in declared if c.name not in inv)

    # --- Stats ---------------------------------------------------------------------------------
    reqs: dict = {}
    for s in m.sessions:
        reqs[root_of[s.id]] = reqs.get(root_of[s.id], 0) + len(s.turns)

    return {
        "history": {
            "installed": len(installed),
            "never_used": never,
            "used_installed": len(installed) - len(never),
            "owners": owners,
            "owner_total": len(never),
            "self_excluded": len(self_names),
            "bundled_absent": sorted(c.name for c in m.capabilities if c.kind == "bundled_skill"),
        },
        "cleanup": {
            "picker": measured_roots,
            "not_in_picker": sorted(set(all_roots) - set(measured_roots)),
            "unused": unused,
            "used": used,
        },
        "stats": {"requests": reqs},
        "skill": {"port": 8788},
    }


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--tier", required=True, choices=("smoke", "full", "stress"))
    ap.add_argument("--out", required=True)
    ap.add_argument("--home", default="/sandbox")
    a = ap.parse_args(argv)
    with open(a.out, "w") as f:
        json.dump(expected(mf.build(a.tier, home=a.home)), f, sort_keys=True, indent=1)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
# e2e/gen/transcripts.py
"""Manifest -> Claude Code transcript files, in the real entry shapes.

Each session file interleaves the entry types a real one has (user, assistant, attachment, and the
small bookkeeping types) so the importer meets realistic noise, and the LAST session's file ends in a
truncated line, as a live session's often does."""
from __future__ import annotations

import argparse
import datetime as dt
import json
import pathlib
import sys

from e2e.gen import manifest as mf


def _iso(ms: int) -> str:
    return dt.datetime.fromtimestamp(ms / 1000, dt.timezone.utc).isoformat().replace("+00:00", "Z")


def _blocks(t: mf.Turn, caps: dict) -> list:
    out = []
    for i, inv in enumerate(t.invocations):
        c = caps[inv.cap]
        if c.kind in ("plugin_skill", "marketplace_skill", "bundled_skill"):
            out.append({"type": "tool_use", "id": f"tu{i}", "name": "Skill", "input": {"skill": c.name}})
        else:
            out.append({"type": "tool_use", "id": f"tu{i}", "name": c.name, "input": {}})
    return out


def _lines(s: mf.Session, caps: dict) -> list:
    out = [json.dumps({"type": "ai-title", "sessionId": s.id, "aiTitle": "work"})]
    for t in s.turns:
        out.append(json.dumps({"type": "user", "sessionId": s.id, "cwd": t.cwd, "timestamp": _iso(t.ts - 1000),
                               "isSidechain": False, "entrypoint": "cli", "gitBranch": "main",
                               "message": {"role": "user", "content": "continue"}}))
        out.append(json.dumps({
            "type": "assistant", "sessionId": s.id, "cwd": t.cwd, "timestamp": _iso(t.ts),
            "isSidechain": False, "entrypoint": "cli", "gitBranch": "main",
            "message": {"model": "claude-opus-5", "role": "assistant", "content": _blocks(t, caps),
                        "usage": {"input_tokens": t.fresh, "cache_read_input_tokens": t.cache_read,
                                  "cache_creation_input_tokens": t.cache_write, "output_tokens": t.output}}}))
    out.append(json.dumps({"type": "last-prompt", "sessionId": s.id, "lastPrompt": "continue", "leafUuid": "x"}))
    return out


def write(m: mf.Manifest, home: str) -> dict:
    caps = {c.name: c for c in m.capabilities}
    projs = {p.key: p for p in m.projects}
    base = pathlib.Path(home) / ".claude" / "projects"
    turns = 0
    for idx, s in enumerate(m.sessions):
        d = base / projs[s.project].transcript_dir
        d.mkdir(parents=True, exist_ok=True)
        lines = _lines(s, caps)
        body = "\n".join(lines) + "\n"
        if idx == len(m.sessions) - 1:
            body += lines[-2][: len(lines[-2]) // 2]  # Review Focus 4: a cut-off final line
        (d / f"{s.id}.jsonl").write_text(body)
        turns += len(s.turns)
    for p in m.projects:  # folders that exist on disk; deleted-proj stays absent
        if p.exists and p.root.startswith(home):
            for f in p.folders:
                if f.startswith(home):
                    pathlib.Path(f).mkdir(parents=True, exist_ok=True)
    return {"files": len(m.sessions), "turns": turns, "truncated_lines": 1}


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--tier", required=True)
    ap.add_argument("--home", required=True)
    a = ap.parse_args(argv)
    print(json.dumps(write(mf.build(a.tier, home=a.home), a.home)))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
import argparse

def _skill(dir_: pathlib.Path, name: str) -> None:
    dir_.mkdir(parents=True, exist_ok=True)
    (dir_ / "SKILL.md").write_text(f"---\nname: {name}\ndescription: e2e fixture skill {name}\n---\n")


def write(m: mf.Manifest, home: str) -> dict:
    h = pathlib.Path(home)
    n_plug = n_mkt = 0
    servers = {}
    for c in m.capabilities:
        if not c.on_disk:
            continue
        if c.kind == "plugin_skill":
            plugin, name = c.name.split(":", 1)
            _skill(h / ".claude/plugins/cache/e2e-market" / plugin / "1.0.0/skills" / name, name)

        elif c.kind == "marketplace_skill":
            _skill(h / ".claude/plugins/marketplaces" / c.owner / "skills" / c.name, c.name)

    cfg_path = h / ".claude.json"

    cfg["mcpServers"] = servers
    cfg_path.write_text(json.dumps(cfg, indent=1, sort_keys=True))
    return {"plugin_skills": n_plug, "marketplace_skills": n_mkt, "mcp_servers": len(servers)}
```

```python
"""Generated transcripts vs the real format: every generated entry type must exist in the reference,
and every key a generated entry carries must be one the real format uses. Keys only."""
from __future__ import annotations

import argparse
import json
import pathlib
import sys


def check(home: str, reference: dict) -> list:
    problems = []
    for f in sorted((pathlib.Path(home) / ".claude" / "projects").glob("*/*.jsonl")):
        for n, line in enumerate(f.read_text().splitlines(), 1):
            try:
                e = json.loads(line)
            except ValueError:
                continue  # the deliberately truncated line; the importer must skip it too
            t = e.get("type", "?")
            if t not in reference:
                problems.append(f"{f.name}:{n} entry type {t!r} never appears in real transcripts")
                continue
            extra = set(e) - set(reference[t])
            if extra:
                problems.append(f"{f.name}:{n} {t} has keys real transcripts never use: {sorted(extra)}")
            if t == "assistant":
                msg = e.get("message") or {}
                extra = set(msg) - set(reference.get("assistant.message", ()))
                if extra:
                    problems.append(f"{f.name}:{n} assistant.message keys not in real data: {sorted(extra)}")
    return problems


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--home", required=True)
    a = ap.parse_args(argv)
    ref = json.loads((pathlib.Path(__file__).parent / "reference_keys.json").read_text())
    p = check(a.home, ref)
    for line in p[:20]:
        print(line)
    return 1 if p else 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""A fake Anthropic /v1/messages for the e2e review: deterministic replies, no model, no key.

Usage comes from a header the replay driver sets, so token counts are the manifest's and repeat
exactly between runs. Streams can be cut short to exercise the proxy's capture of an incomplete SSE."""
from __future__ import annotations

import argparse
import http.server
import json
import sys


def _usage(h) -> tuple:
    raw = h.get("X-E2E-Usage", "1,0,0,1")
    a, b, c, d = (int(x) for x in raw.split(","))
    return a, b, c, d


class _H(http.server.BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"

    def log_message(self, *a):  # quiet; the phase log captures the proxy, not this
        pass

    def do_POST(self):
        n = int(self.headers.get("content-length", 0))
        req = json.loads(self.rfile.read(n) or b"{}")
        fresh, cread, cwrite, out = _usage(self.headers)
        usage = {"input_tokens": fresh, "cache_read_input_tokens": cread,
                 "cache_creation_input_tokens": cwrite, "output_tokens": out}
        msg = {"id": "msg_e2e", "type": "message", "role": "assistant", "model": req.get("model", "m"),
               "content": [{"type": "text", "text": "ok"}], "stop_reason": "end_turn", "usage": usage}
        if not req.get("stream"):
            body = json.dumps(msg).encode()
            self.send_response(200)
            self.send_header("content-type", "application/json")
            self.send_header("content-length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)
            return
        events = [
            ("message_start", {"type": "message_start", "message": {**msg, "content": [],
                               "usage": {**usage, "output_tokens": 0}}}),
            ("content_block_start", {"type": "content_block_start", "index": 0,
                                     "content_block": {"type": "text", "text": ""}}),
            ("content_block_delta", {"type": "content_block_delta", "index": 0,
                                     "delta": {"type": "text_delta", "text": "ok"}}),
            ("content_block_stop", {"type": "content_block_stop", "index": 0}),
            ("message_delta", {"type": "message_delta", "delta": {"stop_reason": "end_turn"},
                               "usage": {"output_tokens": out}}),
            ("message_stop", {"type": "message_stop"}),
        ]
        if self.headers.get("X-E2E-Truncate") == "1":
            events = events[:3]
        payload = "".join(f"event: {e}\ndata: {json.dumps(d)}\n\n" for e, d in events).encode()
        self.send_response(200)
        self.send_header("content-type", "text/event-stream")
        self.send_header("content-length", str(len(payload)))
        self.end_headers()
        self.wfile.write(payload)


def serve(port: int) -> http.server.ThreadingHTTPServer:
    return http.server.ThreadingHTTPServer(("127.0.0.1", port), _H)


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--port", type=int, default=9000)
    serve(ap.parse_args(argv).port).serve_forever()
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Replay the manifest's post-install turns through the proxy, as Claude Code would send them.

Each request declares the full inventory (MCP and built-in tools in `tools`, skills in the system
reminder), names its working directory with the same marker Claude Code writes, and carries the
turn's invocations as tool_use blocks, so the proxy's capture path is exercised for real."""
from __future__ import annotations

import argparse
import json
import sys
import urllib.error
import urllib.request

from e2e.gen import manifest as mf

SKILL_KINDS = ("plugin_skill", "marketplace_skill", "bundled_skill")


def _tool(c: mf.Capability) -> dict:
    return {"name": c.name, "description": f"e2e fixture {c.name} " + "x" * (c.tokens // 4),
            "input_schema": {"type": "object", "properties": {}}}


def body_for(t: mf.Turn, s: mf.Session, m: mf.Manifest, with_marker: bool = True) -> dict:
    caps = {c.name: c for c in m.capabilities}
    declared = [c for c in m.capabilities if c.declared]
    tools = [_tool(c) for c in declared if c.kind not in SKILL_KINDS]
    tools.append({"name": "Skill", "description": "Invoke a skill",
                  "input_schema": {"type": "object", "properties": {"skill": {"type": "string"}}}})
    listing = "\n".join(f"- {c.name}: e2e fixture skill {c.name}" for c in declared if c.kind in SKILL_KINDS)
    reminder = ("<system-reminder>\nThe following skills are available for use with the Skill tool:\n\n"
                + listing + "\n</system-reminder>")
    env = f"# Environment\nPrimary working directory: {t.cwd}\n" if with_marker else "# Environment\n"
    uses = []
    for i, inv in enumerate(t.invocations):
        c = caps[inv.cap]
        if c.kind in SKILL_KINDS:
            uses.append({"type": "tool_use", "id": f"tu{i}", "name": "Skill", "input": {"skill": c.name}})
        else:
            uses.append({"type": "tool_use", "id": f"tu{i}", "name": c.name, "input": {}})
    msgs = [{"role": "user", "content": [{"type": "text", "text": env}, {"type": "text", "text": reminder},
                                         {"type": "text", "text": "continue"}]}]
    if uses:
        msgs.append({"role": "assistant", "content": uses})
        msgs.append({"role": "user", "content": [{"type": "tool_result", "tool_use_id": u["id"], "content": "ok"}
                                                 for u in uses]})
    return {"model": "claude-opus-5", "max_tokens": 1024, "stream": t.stream,
            "system": [{"type": "text", "text": "You are Claude Code."}],
            "tools": tools, "messages": msgs,
            # Claude Code's real shape: user_id is a JSON OBJECT carrying session_id. session.ExplicitID
            # unwraps it (session/session.go metaSessionID); a plain string would skip that path.
            "metadata": {"user_id": json.dumps({"session_id": s.id})}}


def _turns(m: mf.Manifest, which: str):
    post = [(s, t) for s in m.sessions for t in s.turns if mf.measured(t, m)]
    post.sort(key=lambda st: st[1].ts)
    half = len(post) // 2
    return {"post": post, "first_half": post[:half], "second_half": post[half:]}[which]


def run(m: mf.Manifest, base_url: str, which: str = "post", limit=None) -> dict:
    sent = ok = failed = trunc = 0
    for s, t in _turns(m, which)[:limit]:
        body = json.dumps(body_for(t, s, m)).encode()
        h = {"content-type": "application/json", "x-api-key": "sk-e2e-fake",
             "anthropic-version": "2023-06-01",
             "X-E2E-Usage": f"{t.fresh},{t.cache_read},{t.cache_write},{t.output}"}
        if t.truncate:
            h["X-E2E-Truncate"] = "1"
            trunc += 1
        sent += 1
        try:
            with urllib.request.urlopen(urllib.request.Request(
                    base_url.rstrip("/") + "/v1/messages", data=body, headers=h, method="POST"), timeout=30) as r:
                r.read()
                ok += 1
        except (urllib.error.URLError, ConnectionError, TimeoutError):
            failed += 1
    return {"sent": sent, "ok": ok, "failed": failed, "truncated": trunc}


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--tier", required=True)
    ap.add_argument("--base", required=True)
    ap.add_argument("--which", default="post", choices=("post", "first_half", "second_half"))
    ap.add_argument("--home", default="/sandbox")
    a = ap.parse_args(argv)
    r = run(mf.build(a.tier, home=a.home), a.base, a.which)
    print(json.dumps(r))
    return 1 if r["failed"] else 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Read the dashboard API into actual-api.json, for every root the oracle names plus the pooled view."""
from __future__ import annotations

import argparse
import json
import subprocess
import sys
import urllib.parse
import urllib.request


def _get(base: str, path: str):
    with urllib.request.urlopen(base.rstrip("/") + path, timeout=30) as r:
        return json.loads(r.read())


def collect(base: str, exp: dict, skill_cmd) -> dict:
    roots = sorted(set(exp["cleanup"]["picker"]) | set(exp["stats"]["requests"]))
    q = lambda r: urllib.parse.quote(r, safe="")
    out = {
        "history": _get(base, "/api/history"),
        "facets_measured": _get(base, "/api/facets?measured=1"),
        "facets_all": _get(base, "/api/facets"),
        "insights": {"": _get(base, "/api/insights?timeline=1")},
        "stats": {},
    }
    for r in roots:
        out["insights"][r] = _get(base, f"/api/insights?timeline=1&project={q(r)}")
        out["stats"][r] = _get(base, f"/api/stats?project={q(r)}")
    if skill_cmd:
        p = subprocess.run(skill_cmd, capture_output=True, text=True)
        out["skill"] = {"exit": p.returncode, "stdout": p.stdout, "stderr": p.stderr}
    return out


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--base", required=True)
    ap.add_argument("--expected", required=True)
    ap.add_argument("--out", required=True)
    ap.add_argument("--skill", default="")
    a = ap.parse_args(argv)
    exp = json.load(open(a.expected))
    got = collect(a.base, exp, [a.skill, "--no-open"] if a.skill else None)
    json.dump(got, open(a.out, "w"), indent=1, sort_keys=True)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```bash
#!/usr/bin/env bash
# In-container phase runner for the PR #578 review. One function per phase; a phase that crashes
# stops the run (exit 3), a check that fails does not -- checks are judged later, by check.py.
set -uo pipefail
TIER="${1:?tier: smoke|full|stress}"
R=/results; mkdir -p "$R/logs" "$R/snapshots"
PORT=8788; UP=9000; BASE="http://127.0.0.1:${PORT}"
PLUG=/src/context-guru-plugin

phase() {  # phase <name> <function>
  local name="$1" fn="$2" t0 rc; t0=$(date +%s)
  echo "== $name"; "$fn" >"$R/logs/$name.log" 2>&1; rc=$?
  local st=ok; [ $rc -eq 0 ] || st=crashed
  printf '{"phase":"%s","status":"%s","seconds":%d}\n' "$name" "$st" $(( $(date +%s) - t0 )) >>"$R/phases.jsonl"
  if [ $rc -ne 0 ]; then echo "!! $name crashed (rc=$rc); tail:"; tail -20 "$R/logs/$name.log"; exit 3; fi
}

p_preflight() {
  [ "$HOME" = /sandbox ] || { echo "HOME is $HOME, not /sandbox"; return 1; }

    if curl -s -o /dev/null --max-time 1 "http://127.0.0.1:$p/"; then echo "port $p already in use"; return 1; fi
  done
  for c in python3 node chromium curl jq; do command -v $c >/dev/null || { echo "missing $c"; return 1; }; done
  go vet ./dash/ ./proxy/ ./cmd/... && go build ./...
}
```

```python
"""expected.json vs the collected actuals -> one verdict per check.

Every family here has a test that makes it FAIL, so a check that cannot fail is caught before the
harness is trusted. KNOWN is not assigned here: run.sh re-runs a failure on main to decide it."""
from __future__ import annotations

import argparse
import json
import pathlib
import re
import sys

UNATTRIBUTED = ("", "(unattributed)", "none", "(none)")


def _rec(out, id_, area, ok, exp, act, detail="", snapshot="", blocked=False):
    out.append({"id": id_, "area": area, "verdict": "BLOCKED" if blocked else ("PASS" if ok else "FAIL"),
                "expected": exp, "actual": act, "detail": detail, "snapshot": snapshot})


def run(exp: dict, api: dict, ui, tier: str) -> list:
    out = []
    h, he = api.get("history", {}), exp["history"]
    picker = api.get("facets_measured", {}).get("project") or []

    # --- smoke --------------------------------------------------------------------------------
    _rec(out, "S4.history_never_used_count", "history", len(h.get("never_used", [])) == len(he["never_used"]),
         len(he["never_used"]), len(h.get("never_used", [])))
    _rec(out, "S5.picker_excludes_history_only", "cleanup",
         not set(picker) & set(exp["cleanup"]["not_in_picker"]),
         "absent: " + ", ".join(exp["cleanup"]["not_in_picker"]), picker)
    _rec(out, "S5.picker_folds_subfolder", "cleanup",
         all(not any(p != r and p.startswith(r + "/") for p in picker) for r in exp["cleanup"]["picker"]),
         "no subfolder of a root listed", picker)
    port = re.findall(r"127\.0\.0\.1:(\d+)/dashboard", api.get("skill", {}).get("stdout", ""))
    _rec(out, "S7.skill_port", "skill", port and all(p == str(exp["skill"]["port"]) for p in port),
         exp["skill"]["port"], port)
    pages = (ui or {}).get("pages", {})
    _rec(out, "S6.ui_no_js_errors", "ui", pages and not any(p["errors"] for p in pages.values()),
         "no JS errors on any page", {k: v["errors"] for k, v in pages.items() if v["errors"]},
         blocked=not pages)
    if tier == "smoke":
        return out

    # --- history ------------------------------------------------------------------------------
    _rec(out, "H.never_used_set", "history", sorted(h.get("never_used", [])) == he["never_used"],
         he["never_used"], sorted(h.get("never_used", [])))
    _rec(out, "H.partition", "history",
         h.get("used_installed", -1) + len(h.get("never_used", [])) == h.get("installed_skills", -2),
         "used + never == installed", [h.get("used_installed"), len(h.get("never_used", [])), h.get("installed_skills")])
    got_owners = {g["owner"]: len(g["skills"]) for g in h.get("never_used_owners", [])}
    _rec(out, "H.owner_counts", "history", got_owners == he["owners"], he["owners"], got_owners)
    _rec(out, "H.self_excluded", "history", (h.get("self_excluded") or {}).get("items") == he["self_excluded"],
         he["self_excluded"], (h.get("self_excluded") or {}).get("items"))
    used_names = {u["name"] for u in h.get("used", []) if u.get("skill")}
    _rec(out, "H.bundled_not_used", "history", not used_names & set(he["bundled_absent"]),
         "absent: " + ", ".join(he["bundled_absent"]), sorted(used_names & set(he["bundled_absent"])))

    # --- cleanup ------------------------------------------------------------------------------
    _rec(out, "C.picker_set", "cleanup", sorted(picker) == exp["cleanup"]["picker"], exp["cleanup"]["picker"], sorted(picker))
    _rec(out, "C.picker_has_no_unattributed_entry", "cleanup", not set(picker) & set(UNATTRIBUTED),
         "no unattributed entry", [p for p in picker if p in UNATTRIBUTED])
    ins = api.get("insights", {})
    project_totals = []
    for root in exp["cleanup"]["picker"]:
        doc = ins.get(root, {})
        items = doc.get("items", [])
        unused = sorted(i["name"] for i in items if not i.get("invoked"))
        _rec(out, f"C.unused_set.{root}", "cleanup", set(exp["cleanup"]["unused"][root]) <= set(unused),
             exp["cleanup"]["unused"][root], unused, "every expected unused item is listed")
        _rec(out, f"C.used_absent.{root}", "cleanup",
             not set(exp["cleanup"]["used"][root]) & set(unused), "none listed as unused",
             sorted(set(exp["cleanup"]["used"][root]) & set(unused)))
        _rec(out, f"C.money.unused_positive.{root}", "money",
             all(i.get("usd", 0) > 0 for i in items if not i.get("invoked")), "usd > 0 for every unused item",
             [i["name"] for i in items if not i.get("invoked") and not i.get("usd", 0) > 0])
        total = round(sum(i.get("usd", 0) for i in items if not i.get("invoked")), 6)
        _rec(out, f"C.money.total_is_sum.{root}", "money", abs(total - doc.get("removable_usd", 0)) < 1e-6,
             total, doc.get("removable_usd"))
        project_totals.append(doc.get("removable_usd", 0))
    pooled = ins.get("", {}).get("removable_usd", 0)
    _rec(out, "C.money.pooled_ge_project", "money", all(pooled + 1e-9 >= t for t in project_totals),
         f">= max project ({max(project_totals or [0])})", pooled)

    # --- requests -----------------------------------------------------------------------------
    for root, n in exp["stats"]["requests"].items():
        got = (api.get("stats", {}).get(root) or {}).get("requests")
        _rec(out, f"R.requests.{root}", "rollup", got == n, n, got)

    # --- ui -----------------------------------------------------------------------------------
    for name, p in pages.items():
        _rec(out, f"U.no_js_errors.{name}", "ui", not p["errors"], [], p["errors"], snapshot=f"snapshots/{name}.png")
        _rec(out, f"U.no_overflow.{name}", "ui", not p["overflow"], [], p["overflow"], snapshot=f"snapshots/{name}.png")
        low = {k: v for k, v in p.get("contrast", {}).items() if v < 3.0}
        _rec(out, f"U.contrast.{name}", "ui", not low, ">= 3:1", low, snapshot=f"snapshots/{name}.png")

            _rec(out, f"U.headline_matches_api.{name}", "ui",
                 p["values"]["headline_never"] == len(h.get("never_used", [])),
                 len(h.get("never_used", [])), p["values"]["headline_never"], snapshot=f"snapshots/{name}.png")
    return out


def main(argv=None) -> int:

    ap.add_argument("--results", required=True)
    ap.add_argument("--tier", required=True)
```

```bash
#!/usr/bin/env bash
# The mutation round: break the PR in five known ways, one at a time, and confirm each break turns
# its check red. A break that stays green is a gap in the harness, reported -- never ignored.
# Runs the SMOKE tier for speed, except `rollup`, which needs gamma's subfolders (full tier).
set -uo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"; cd "$ROOT"
git diff --quiet -- dash context-guru-plugin || { echo "working tree has changes under dash/ or the plugin; refusing"; exit 2; }
OUT="$ROOT/e2e/results/$(date -u +%Y%m%dT%H%M%SZ)-mutation"; mkdir -p "$OUT"
echo '[' >"$OUT/mutation.json"; first=1; missed=0
for f in e2e/mutations/*.file; do
  id="$(basename "$f" .file)"; file="$(cat "$f")"; expect="$(cat "e2e/mutations/$id.expect")"
  n="$(python3 -c "import sys;print(open(sys.argv[1]).read().count(open(sys.argv[2]).read()))" "$file" "e2e/mutations/$id.from")"
  [ "$n" = 1 ] || { echo "$id: anchor occurs $n times in $file; fix the mutation file"; exit 2; }
  cp "$file" "$OUT/$id.orig"
  python3 -c "import sys;p,a,b=sys.argv[1:];s=open(p).read();open(p,'w').write(s.replace(open(a).read(),open(b).read()))" \
    "$file" "e2e/mutations/$id.from" "e2e/mutations/$id.to"
  tier=smoke; [ "$id" = rollup ] && tier=full
  e2e/run.sh "$tier" >"$OUT/$id.log" 2>&1
  cp "$OUT/$id.orig" "$file"                     # restore BEFORE judging, so a crash below cannot leave it broken
  run="$(ls -d e2e/results/*-"$tier" | tail -1)"
  red="$(python3 -c "import json,sys;v=json.load(open(sys.argv[1]+'/verdicts.json'));print(','.join(r['id'] for r in v if r['verdict']=='FAIL'))" "$run" 2>/dev/null)"
  crashed="$(grep -c '"crashed"' "$run/phases.jsonl" 2>/dev/null || echo 0)"
  caught=false; case ",$red," in *",$expect"*) caught=true;; esac
  [ "$crashed" != 0 ] && caught=true             # a break that crashes a phase is caught too, and says so
  $caught || missed=$((missed+1))
  [ $first = 1 ] || echo ',' >>"$OUT/mutation.json"; first=0
  printf '{"id":"%s","file":"%s","expect":"%s","caught":%s,"crashed_phase":%s,"turned_red":"%s","run":"%s"}' \
    "$id" "$file" "$expect" "$caught" "$([ "$crashed" != 0 ] && echo true || echo false)" "$red" "$run" >>"$OUT/mutation.json"
  echo "$id: caught=$caught red=[$red]"
done
echo ']' >>"$OUT/mutation.json"
git diff --quiet -- dash context-guru-plugin || { echo "RESTORE FAILED: tree differs after mutation round"; git diff --stat; exit 4; }
echo "results: $OUT  missed: $missed"
exit $missed
```
