# Documentation site — MkDocs core plus the theme in `theme/`.
# Build: pip install -r requirements-docs.txt && mkdocs build --strict
#
# There is no theme package here on purpose: the site's design system is the
# hand-written theme in `theme/` (one stylesheet, one JS file, four templates,
# one build hook), so the only third-party pieces are the Markdown engine and
# its extensions.
#
# Upper bounds are deliberate. MkDocs 2.0 is announced as removing the plugin
# and theming systems outright, and `theme/` depends on both — an unpinned major
# bump would break the published site silently.
mkdocs>=1.6,<2
pymdown-extensions>=10.7,<11
# Explicit, not incidental. Pygments is an *optional* dependency of
# pymdown-extensions — it used to arrive via mkdocs-material. Without it
# `pymdownx.highlight` silently degrades to plain `<pre><code>` and every code
# block on the site ships uncoloured, which a passing `mkdocs build --strict`
# will not tell you. theme/css/pygments.css is generated from its `github-dark`
# style, so the major version is pinned alongside it.
pygments>=2.17,<3
