Cumulative cost: without context-guru vs with

The shaded area between the lines is money saved. Baseline prices the unique tokens we removed at the cache-write rate they would have entered as (~11.5× a cache read on a prompt-caching backend), and the re-sent remainder at the cache-read rate the provider would have served it from. Pricing gross savings as writes is how a dashboard overstates itself by its own overcount ratio — which is why dollar savings and token savings diverge so sharply on this workload.

Point your agent at context-guru

One token, one host. Each agent reads a different environment variable, so set each once and never think about it again. The token below is a placeholder unless you have just minted one — substitute yours.

If something goes wrong

  • Unset the base URL to bypass context-guru entirely — your agent talks to the gateway directly, exactly as before.
  • Send x-context-guru-bypass: true to keep the metrics but skip compaction, which is the way to A/B a suspicion.

Compaction

Tokens

Tokens are stored hashed, so a lost token cannot be recovered — mint a new one and revoke the old. Several can be live at once, which is how you rotate without downtime.

Signed-in machines

You can be signed in on several machines at once. Revoking one signs that browser out and leaves the others alone — use it if you lose a laptop.

Recent configuration changes

Tenants

Metrics and configuration for every account. Transcripts are deliberately not here: reading another person's source code is not an administrative need.

Effective configuration

The resolved configuration — preset expanded, defaults filled, overrides applied — not what was typed. Visible from loopback or a trusted CIDR only, and key-allowlisted even then.
